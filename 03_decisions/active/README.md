# 进行中的重大决策（Active Decisions）

本目录存放所有尚未拍板的 L2 / L3 重大决策提案（基于 `../templates/decision_proposal.md`）。

- 命名规范：`YYYY-MM-DD-<domain>-<简短议题>.md`
- `scripts/proactive_radar.py` 会自动扫描本目录下所有提案的 `deadline`，临近或过期时主动推入 `00_radar.md` 预警。
- 定案后由 AI 移至 `../log/`，并在 `../log/README.md` 登记复盘到期日。
